# Customer Churn Prediction

## About the Project
This project uses machine learning to predict whether a customer is likely to leave a telecom company.

## Dataset
Used the IBM Telco Customer Churn dataset.

## Models Used
- Logistic Regression
- Random Forest
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Classifier (SVC)

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Loaded and cleaned the dataset.
2. Prepared the data for machine learning.
3. Trained and tuned five machine learning models.
4. Compared model performance using accuracy, precision, recall, F1-score, and ROC-AUC.
5. Selected Random Forest as the final model based on its overall performance.

## Results
Random Forest achieved an accuracy of **78.76%** and a churn F1-score of **0.67** on the test data.

## Conclusion
This project helped identify customers who may leave the company and understand the factors related to customer churn.
